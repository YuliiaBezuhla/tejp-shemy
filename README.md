# Схемы кинезиотейпа

Личный архив схем тейпирования. Приватный: на схемах есть стоковые фото и рисунки, поэтому не публиковать.

## Что внутри

| Папка | Что это |
|---|---|
| [`sheya-plecho/`](sheya-plecho/) | Боль в шее с отдачей в правое плечо, ключицу и лопатку (21.11.2026). Страница `index.html`, PDF для отправки `tejp-sheya-plecho.pdf`, картинки полос и пошаговые фото. |
| [`po-zonam/`](po-zonam/) | Справочник «Тейп по зонам тела»: живот (диастаз), спина, руки, ноги, декольте, шея, лицо. Страница `index.html` и картинки-схемы. |

Страницы `index.html` открываются в браузере после скачивания папки целиком (картинки лежат рядом).

Тейп не заменяет осмотр врача. Красные флаги, при которых нужно к врачу, расписаны на каждой странице.
